DeltaCOOP is a Roleplay Project Mod for Super Mario 64 Coop Deluxe.
Has an API for custom characters and maps called SURVEY API!
It's very easy to use, so i'm pretty sure you could make your own characters to be in DeltaCOOP!
Awesome, Right?

This is all worked for fun, so feel free to suggest stuff!
