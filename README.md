DeltaCoop is a Roleplay Project Mod for Super Mario 64 Coop Deluxe that includes an API for custom characters and custom maps called SURVEY_API! It's very easy to use, So i'm pretty sure you could make your own characters to be in DeltaCOOP! Awesome, Right? There's also a warp api in the SURVEY_API making custom warps.

This is all worked for fun, So feel free to suggest stuff!

## Community

We have an official Discord server open to the public [here](https://discord.gg/QNJD2enFcm)! On that Discord server, We post Devlogs, Playtest announcements, And much more!
